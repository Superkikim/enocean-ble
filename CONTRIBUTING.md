# Contributing

Thanks for your interest in contributing!

## Branches

- **`dev`** is the development branch. **Open all pull requests against `dev`.**
- **`main`** is reserved for releases. Please do not target it.

## Pull requests

1. Fork the repository and create a feature branch from `dev`.
2. Keep your changes focused; one topic per PR.
3. Run the same checks as CI before submitting: `ruff check .`, `mypy custom_components tests` and `pytest`.
4. Open the PR against `dev` and describe what it changes and why.
